## 1. 概要 (Overview)

| モード | ノード名 / Launch | 特徴・役割 |
| :--- | :--- | :--- |
| **Game2 Auto** | `game2_aim` / `game2_auto.launch.py` | **9マスの全自動射出**。<br>カメラで起立状態を常時把握し、2枚抜き（中点狙い）を含む最適な的を自動選択して連続射出。 |
| **PK Auto** | `pk_aim_node` / `pk_auto.launch.py` | **手動1点指定射出**。<br>十字キーで狙う的を選択（倒れた的は自動スキップ）、外側列（Col 0/2）の単体撃ち抜き時における外側オフセット（隣接的の誤爆防止）を搭載。○ボタン確定でベルト回転、L2+○で安全射出。 |

## 3. 状態遷移 (State Machine)

### Game2 Auto モード
- **STANDBY**: 手動待機状態。
- **SEARCHING**: カメラで9マスの起立状況をスキャンし、最適な的（直前射出的除外・2枚抜き優先）を自動ロック。
- **ALIGNING**: ロックした的の方向へ機体を自動旋回。
- **PREPARING_SHOOT**: 照準角度合致（誤差 < 0.46deg）で段に応じたベルト回転開始。
- **SHOOTING / WAITING_RESULT**: 射出サイクル実行。
- **COMPLETED**: 全的倒れで終了。

### PK Auto モード
- **STANDBY**: 手動待機状態（ベルトは停止）。
- **SEARCHING**: 十字キーで的を選択待機（倒れた的は自動スキップ）。
- **ALIGNING**: 選択した的へ向けて機体を自動旋回（ベルトは停止維持）。
- **PREPARING_SHOOT**: 照準合致状態で○ボタンを押すと確定（段に応じたベルト回転開始）。
- **射出後**: 射出完了（または保険タイマー）で自動的にベルト停止し `SEARCHING` へ復帰。

## 4. コントローラー操作マニュアル (Controller Keymap)

### PK モード操作一覧
| ボタン操作 | 動作内容 |
| :--- | :--- |
| **PK 開始ボタン** | PKモードへ移行（`SEARCHING` 待機へ）。 |
| **十字キー ⬅️ / ➡️** | 狙う的を左右に切り替え。<br>※ **倒れている的は自動でスキップ** されます（全倒れ時は維持）。 |
| **○ ボタン** | 照準が合致した状態で押すと **射出確定（ベルト回転開始）**。<br>※ 照準が合っていない状態では誤射防止のため確定されません。 |
| **L2 + ○ ボタン** | **射出サイクル（ばね引込 → 送り込み → 復帰）を実行**。 |
| **非常停止 / 手動切替** | 直ちに `STANDBY` に移行し、**ベルトを即時停止** します。 |

## 5. 🛡️ 例外処理・安全仕様 (Fail-Safe & Exception Handling)

現場での誤動作・暴走・誤射を防ぐため、以下のフェイルセーフが組み込まれています。

### ① 照準中・待機中に的を見失った場合
- **PK モード**:
  - 選択中の的がカメラで見えなくなると、ロックを解除して **`SEARCHING`（その場待機）** に戻ります。
  - **未検出の状態で勝手に旋回することはありません**（カメラに的が映るまで機体は静止待機します）。
- **Game2 モード**:
  - `align_lost_timeout`（3.0秒）以上見失うと、目標を破棄して `SEARCHING` に戻り、全体探索を再開します。

### ② 射出準備中（ベルト回転中）の外力・ズレによるアボート
- `PREPARING_SHOOT` 中に機体が押されたりスリップして照準誤差が **約2.3度以上（`yaw_tolerance * 3`）** ズレた場合：
  - **即座に射出確定フラグを破棄し、ベルトを停止して `ALIGNING`（再照準）へ引き戻します**。
  - 照準がズレた状態での誤射を物理的に防止します。

### ③ 射出完了の保険タイマー（Fallback Timer）
- 射出ボタン（L2+○）を押した後、何らかの通信不調で `/shot_cycle/state` の完了応答が届かない場合：
  - **5.0秒（`shot_fallback_timeout`）経過で強制的にベルトを停止し、確定フラグを解除して `SEARCHING` へ安全に復帰** します。

### ④ 手動操作（`STANDBY`）の完全独立
- `STANDBY` に移行する瞬間、**1度だけ `BeltMode::STOP` を送信してベルトを停止** します。
- `STANDBY` 中は自動ノードがコマンドを一切送信しないため、コントローラーの手動操作（足回り・ベルト）を妨害しません。

## 6. 主な ROS 2 トピック (Topics)

### サブスクライブ (購読)
- `/detections` (`apriltag_msgs/AprilTagDetectionArray`): AprilTag 認識結果
- `/camera/camera_info` (`sensor_msgs/CameraInfo`): カメラ内部パラメータ
- `/imu/data` (`sensor_msgs/Imu`): 機体姿勢ジャイロ・ダンピング用
- `/shot_cycle/state` (`robot_msgs/ShotCycleState`): 射出シーケンス状態 (`IDLE`, `FEEDING`, `RETURNING` 等)
- `/shot_cycle/request` (`std_msgs/Bool`): 射出ボタン押下通知

### パブリッシュ (配信)
- `/drive/cmd_vel` (`geometry_msgs/Twist`): 旋回照準角速度コマンド
- `/belt/command_mode` (`robot_msgs/BeltMode`): ベルト回転段数指示 (`STOP`, `LEVEL_1`, `LEVEL_2`, `LEVEL_3`)
- `/target_grid_state` (`robot_msgs/TargetGridState`): 9マスの起立/倒れ/選択状態 (20Hz配信)
- `/pk/state` / `/game2/state` (`robot_msgs/Game2State`): 自動エイムのステートマシン状態

## 7. ⚙️ パラメータ設定・重要度別ガイド (`config/*_auto_aim.yaml`)

パラメータは役割・調整頻度・危険度に応じて以下の **3つに分類** されます。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔴 グループA: 現場・実行ごとに精密調整が必要なパラメータ (Tuning Parameters) │
├─────────────────────────────────────────────────────────────────────────────┤
│ ⚠️ グループB: 一度決めたら固定だが、値をミスるとバグ・暴走を起こす要注意パラメータ│
├─────────────────────────────────────────────────────────────────────────────┤
│ 🔵 グループC: 機体物理・光学寸法に基づく完全固定パラメータ (Hardware Constants)   │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 🔴 グループA: 現場・実行ごとに精密調整が必要なパラメータ
床面の摩擦、バッテリー電圧、射出機構のクセに応じて微調整するパラメータです。

| パラメータ名 | 型 | デフォルト | 役割と調整方法 |
| :--- | :---: | :---: | :--- |
| `aim_yaw_offset_deg` | `double` | `2.0` | **射出方向の左右オフセット補正 [deg]**。<br>実際に打ってボールが右にズレる場合はプラス（例: `+2.0` で左向き補正）、左にズレる場合はマイナスに調整。 |
| `outer_col_offset_m` | `double` | `0.10` | **PK専用: 外側列(Col 0/2)の単体狙い外側シフト量 [m]**。<br>外側の的（左列: Tag 14/17/20, 右列: Tag 16/19/22）を単体で狙う際、ボールの内側接線が的中心を通るように外側へシフトし、隣接する中央列の巻き込み誤爆を物理的に防止。 |
| `kp_yaw` | `double` | `1.1` | **旋回PD制御の比例ゲイン**。<br>照準の動きが遅い場合は上げ、行き過ぎてオーバーシュートする場合は下げる。 |
| `kd_yaw` | `double` | `0.35` | **IMU ジャイロ制動ダンピングゲイン**。<br>旋回停止時の通り過ぎ・スリップを抑えるブレーキ力。 |
| `yaw_tolerance` | `double` | `0.008` | **照準角度誤差の許容値 [rad]** (約0.46度)。<br>4m先で横ズレ±3.2cmの高精度。素早く撃ちたい場合は `0.015` (~0.86度) に緩める。 |
| `test_alignment_only` | `bool` | `false` | **テストモード切替**。<br>`true` にするとベルトや射出機構を動かさず、車体の角度合わせ（旋回）だけを安全にテスト可能。 |
| `test_panel_state_display` | `bool` | `false` | **ターミナル診断出力**。<br>`true` で 0.5秒おきに9マスの起立・選択状況をターミナルにカラー表示。 |

---

### ⚠️ グループB: 一度決めたら固定だが、ミスるとバグ・暴走を起こす要注意パラメータ
基本的に変更不要ですが、**不適切な数値を設定すると射出不能や停止不能を引き起こす** 重要パラメータです。

| パラメータ名 | 型 | デフォルト | ミスした時の危険性と注意点 |
| :--- | :---: | :---: | :--- |
| `shot_fallback_timeout` | `double` | `5.0` | **射出完了保険タイマー [s]**。<br>⚠️ **小さすぎる (例: 1.0s)** と、ボールが発射される前にベルトが強制停止して不発になります。<br>⚠️ **大きすぎる (例: 20s)** と、通信途絶時にベルトが回り続けてしまいます。推奨: `3.0` 〜 `5.0`。 |
| `tag_lost_timeout` | `double` | `3.0` | **タグ見失い判定時間 [s]**。<br>⚠️ **小さすぎる (例: 0.1s)** と、旋回中のカメラブレで一瞬見失っただけでロックが外れてカクつきます。<br>⚠️ **大きすぎる (例: 10s)** と、すでに倒れた的に向かって照準し続けてしまいます。 |
| `align_lost_timeout` | `double` | `3.0` | **照準中・射出準備中の完全見失い復帰時間 [s]**。<br>タグが完全に隠れたときに `SEARCHING` へ安全に戻るまでの待機時間。 |
| `min_angular_z` | `double` | `0.015` | **静止摩擦補償最小角速度 [rad/s]**。<br>⚠️ **大きすぎる** と、目標付近でカクカクと行き過ぎてハンチングします。<br>⚠️ **小さすぎる** と、床の摩擦に負けて照準完了角度まで動ききれず停止します。 |
| `max_angular_z` | `double` | `0.25` | **最大旋回角速度 [rad/s]** (~14 deg/s)。<br>カメラのブレを防ぎつつ安全に旋回する上限値。高すぎると画像が流れてタグロストします。 |
| `max_angular_accel` | `double` | `1.5` | **旋回加減速度リミッター [rad/s^2]**。<br>急制動時のスリップ・飛び出しを防ぐスルーレートリミッター。 |
| `yaw_command_sign` | `double` | `-1.0` | **機体旋回コマンド符号**。<br>⚠️ **絶対に `+1.0` に反転させないこと**（目標と真逆に回り続けて発散・暴走します）。 |
| `top_tags` / `middle_tags` / `bottom_tags` | `array` | `[14..22]` | **AprilTag IDマッピング**。<br>⚠️ 配列の順序やIDを間違えると、狙う段数とベルト回転段数が狂います。 |

---

### 🔵 グループC: 機体物理・光学寸法に基づく完全固定パラメータ
ロボットのハードウェア寸法およびカメラキャリブレーション値です。機構を変更しない限り **変更禁止** です。

| パラメータ名 | 値 | 内容・測定根拠 |
| :--- | :---: | :--- |
| `camera_offset_x` | `0.265` | [m] 機体中心からカメラの前方オフセット (実測: 265mm) |
| `camera_offset_y` | `0.035` | [m] 射出口からカメラの左オフセット (実測: 35mm) |
| `camera_offset_z` | `0.193` | [m] 機体底面からカメラの高さ (実測: 193mm) |
| `camera_image_width` / `height` | `1920.0` / `1080.0` | カメラ解像度 (Full HD) |
| `camera_fx` / `camera_fy` | `800.0` / `800.0` | 水平・垂直焦点距離 [px] |
| `camera_cx` / `camera_cy` | `960.0` / `540.0` | 光学中心座標 (画像中央) |
| `target_distance` | `4.0` | 想定射出距離 (4.0m) |
| `base_frame` | `"base_link"` | 機体座標系フレーム名 |

## 8. 起動手順 (Launch Commands)

### PK モードの起動
```bash
ros2 launch robot_bringup pk_auto.launch.py
```

### Game2 モードの起動
```bash
ros2 launch robot_bringup game2_auto.launch.py
```

### 単体ノードのテスト起動
```bash
ros2 launch robot_bringup pk_aim.launch.py
# または
ros2 launch robot_bringup game2_auto_aim.launch.py
```
