# ロボット LED 発光モード＆カラーガイド

本ドキュメントでは、ロボットのステータス表示用 LED（STM32制御）の色および点滅・アニメーションパターンの意味を解説します。

---

## 🔴 赤点滅 vs 🔴 赤流れる（アニメーション）の違い

| LED パターン | 状態名 | 意味・原因 | 対処法 / 状態解説 |
|---|---|---|---|
| 🔴 **赤点滅** | **EMERGENCY_STOP<br>（非常停止モード）** | ・PSボタン等で非常停止がオンになっている<br>・コントローラーの通信が切断された（タイムアウト） | コントローラーの **PSボタン** を押して解除、または有線ケーブルを接続 |
| 🔴 **赤流れる<br>（ウェーブ/シークエンス）** | **REVERSED / ACTION<br>（前後反転 / 動作中）** | ・操縦の前後反転モード（PSボタン）がON<br>・装填・射出シークエンス中 | コントローラーの PSボタン（前後反転切替）を押すか、動作完了を待つ |

---

## 🎨 LED カラー＆パターン一覧

| LED 色 / アニメーション | 意味 | 状態の説明 |
|---|---|---|
| 🔵 **青点滅 / 青点灯** | **READY (通常待機)** | 通信が正常に確立され、操作可能な通常状態 |
| 🔴 **赤点滅** | **EMERGENCY STOP (非常停止)** | 非常停止中。全モータがロック・停止しています |
| 🟢 **緑流れ / 緑点灯** | **FIRING / LOADING (射出/装填)** | キッカー（ばね）発射時やボール装填中の動作表示 |
| 🟡 **黄流れ / 黄点灯** | **GAME2 (自動制御モード)** | Game2 自動認識・自動追尾ターゲットサーチ中 |
| 🔴↔️🔵 **前後色反転** | **DRIVE REVERSED (前後反転)** | ロボットの操縦前後方向が反転されている状態 |

---

## 🛠️ コントローラー操作と LED の変化

- **PSボタン (HOME)** ➔ 非常停止の解除 (赤点滅 ➔ 青点滅/青点灯)
- **PSマーク短押し** ➔ 前後反転の切替 (前後のLED色が入れ替わる)
- **R1 ボタン** ➔ ドリブルON/OFF
- **L1 ボタン** ➔ シュート射出 (一瞬緑色にフラッシュ)
